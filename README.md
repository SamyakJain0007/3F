Integramind Bootcamp Projects

Responsive LinkedIn UI built from scratch using only HTML and CSS.

Login Page

Clean, modern login form—demonstrates form design and layout fundamentals.

Todo List

Minimal design for managing tasks.

Fully interactive: add, remove, and mark tasks using JavaScript.

Calculator

UI for a basic calculator, applying layout and styling practice.

MakeMyTrip Frontend Clone (HTML & CSS)

Landing page inspired by MakeMyTrip with contemporary travel visuals.
